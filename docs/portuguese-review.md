# Бразильский португальский: данные и проверка

## Частотный словарь

`data/portuguese/vocabulary.json` содержит 5000 уникальных токенов из отдельного
корпуса **FrequencyWords / OpenSubtitles 2018, pt_br**. Это самостоятельная
бразильская выборка, а не перевод английского или испанского списка.
Источник закреплён на коммите `525f9b560de45753a5ea01069454e72e9aa541c6`.

`frequency-source.txt` сохраняет первые 5633 строки оригинала. Полный источник
и срез имеют SHA-256 в `source.json`. Выборка воспроизводится так:

1. Сохранить исходные номера строк `rank` и частоты `frequency`.
2. Оставить буквенные португальские токены, в том числе с диакритикой и дефисами;
   одиночные буквы — только `a/e/o/é/à/ó`.
3. Применить `excluded.txt`: 612 токенов, включая отдельные имена, иностранный шум,
   обрывки, неподтверждённые записи и устаревшие написания.
4. Взять первые 5000 записей в исходном порядке.

Нормативные слияния (`ao`, `dela`, `nisso`), употребительные сокращения,
разговорные формы и словоформы сохранены. Помета словаря «abbreviation» сама
по себе не исключает грамматическое слияние. `ir`, `vou`, `fui` остаются разными
вопросами. Частотность субтитров не является универсальным рейтингом языка.

Уровни — первые 1000, 3000 или 5000 записей результата. Порядок строгий:
**частотный уровень → тема → перемешивание**. Вопросы, варианты и индекс
обратных синонимов используют только этот набор. Недостающие слова не
подмешиваются из старших уровней. В полном режиме проходится весь набор,
в экспрессе — до 20 записей без повторов.

## Переводы и темы

Просмотрены все 5000 пар с использованием португальского Викисловаря
(Vuizur / Kaikki / Wiktextract), OpenRussian и справочника спряжений
mlconjug3 / Ars-Linguistica. Версии, контрольные суммы, лицензии и изменения
сохранены в `source.json`, `references.json` и [NOTICE.md](../data/portuguese/NOTICE.md).

Учтены бразильские значения и ложные друзья: `celular` — «мобильный телефон»,
`time` — «команда», `trem` — «поезд», `apelido` — «прозвище», `sobrenome` —
«фамилия», `oficina` — «мастерская», `sucesso` — «успех». Исправлены род,
число и глагольные формы. `cartão` принимает «карта/карточка», `prova` —
в том числе «доказательство/подтверждение/улика».

У всех слов явно размечены темы. `topicTranslations` ограничивает значения,
а `meaningAliases` привязывает дополнительные синонимы к точному смыслу:

- `banco`: работа → «банк», дом → «скамья/скамейка»;
- `prova`: закон → «доказательство», еда → «проба», учёба → «экзамен/проверка»;
- `carta`: общение → «письмо», досуг → «игральная карта», еда → «меню»;
- `vela`: дом → «свеча», путешествия → «парус»;
- `pasta`: работа → «папка/портфель», еда → «паста».

В обратном ручном вводе допустимы слова с тем же основным русским значением
из выбранного уровня и темы, включая не попавшие в текущий экспресс.
Например, `você` и `tu` принимаются как «ты» на базовом уровне;
разговорное `vc` принимается только на уровне, в который оно входит.
Поле `choiceFamily` группирует родственные глагольные формы: они не
предлагаются друг другу как заведомо неправильные варианты. Это поле не
расширяет набор ответов при ручном вводе.

Регистр, пунктуация, пробелы, Unicode-композиция и русское ё/е нормализуются.
Португальская диакритика сохраняется: `e/é`, `por/pôr`, `esta/está`, `pais/país`,
`avó/avô`, `pode/pôde`, `tem/têm` — разные формы. Произвольные опечатки
не принимаются. Достаточно одного указанного перевода. Словарные значения
не исчерпывают все контексты языка; автоматические проверки не заменяют
независимую экспертную языковую редактуру.

## Выражения и конструкции

`expressions.tsv` содержит 500 формул общения, связок, идиом и пословиц.
`verb-constructions.tsv` содержит 500 перифраз, глаголов с управлением
и устойчивых глагольных сочетаний. Это учебные подборки бразильского
употребления, а не статистические рейтинги или кальки английских phrasal verbs.

Примеры: `mamão com açúcar` — «проще простого», `por via das dúvidas` —
«на всякий случай», `se dar conta de` — «осознавать/замечать»,
`dar conta de` — «справляться с», `fazer uma vaquinha` — «собирать деньги
в складчину», `acabar de fazer algo` — «только что что-либо сделать».

Каждый набор доступен в двух направлениях, по 500 или 20 вопросов,
только с четырьмя вариантами. `phrase-exclusions.json` хранит смысловые группы,
которые не должны становиться неверными вариантами друг для друга.
Совпадающие русские переводы исключаются также самим движком.

## Проверки и сборка

`npm run check` проверяет воспроизводимость всех шести HTML и модульные тесты.
`tests/portuguese.test.js` проверяет все 5000 частотных записей, все указанные
переводы, варианты во всех уровнях и темах, 528 сочетаний настроек,
попытки, пропуски, результаты, перезапуск, независимые примеры и оба набора
по 500 в обоих направлениях.

Браузерные команды (Python + Playwright + Chromium):

```sh
python tests/browser-portuguese.py
QUIZ_LANGUAGE=pt-BR python tests/browser-compat.py
QUIZ_LANGUAGE=pt-BR python tests/browser-phrases.py
python tests/browser-layout.py
```

Языковая матрица проверяет 1056 сочетаний настроек: 528 с обычными API и
528 с удалёнными современными API старых Safari. Экспрессы завершаются;
проверяются реальные обработчики форм, три попытки, раскрытие ответа,
автопереход, пропуск, переводы ошибок, статистика и повторный запуск.
Переходы между всеми тремя языками сохраняют тип страницы.
Проверка касаниями отдельно охватывает 48 сочетаний, тест выражений —
4160 завершённых вопросов. Проверка макета сравнивает 19 общих элементов
всех шести страниц на девяти ширинах от 320 до 1440 px.
Это Chromium, а не испытания на физическом iPhone или в WebKit.

Португальский использует общие шаблоны и движки. Цвета флага Бразилии
задаются в `src/portuguese.css`: зелёный `#009c3b`, жёлтый `#ffdf00`,
синий `#002776`; для текста и кнопок используются также более тёмные оттенки.
Крупный переключатель языков одинаков на всех страницах.
Атрибуты `lang` соответствуют `pt-BR` и `ru`. Исторический ключ `english`
в формате вариантов и фраз содержит португальский текст на этих страницах.

Для сборки нужен только Node.js 18+ и локальные данные. Морфологические модели,
Python и временные инструменты подготовки словаря не являются зависимостями
приложения. Каждая HTML-страница содержит словарь, скрипты и стили и работает
без сетевых запросов после загрузки. На iPhone открывайте веб-ссылку в Safari:
предпросмотр HTML из «Файлов» или мессенджера может не выполнять JavaScript.

`npm run publish:pages` публикует шесть HTML, лицензии и атрибуцию трёх языков
из сохранённого коммита в `gh-pages`, сохраняя историю. Рабочая ветка при этом
не переключается; `master` и `main` не изменяются.
