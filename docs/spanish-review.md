# Испанский раздел: словарь, значения и проверка

## Выборка

В `data/spanish/vocabulary.json` ровно 5000 уникальных испанских токенов.
Это самостоятельная выборка **Spanish 2018 / OpenSubtitles**, а не перевод
английских 5000 слов. Корпус FrequencyWords зафиксирован на коммите
`525f9b560de45753a5ea01069454e72e9aa541c6`.

`frequency-source.txt` содержит первые 5545 строк оригинала; SHA-256 полного
источника и среза записаны в `source.json`. Для повторения выборки:

1. Сохранить исходные номера строк `rank` и частоты `frequency`.
2. Оставить слова из букв `a–z`, `áéíóúüñ`; одиночные буквы — только `a/e/o/u/y`.
3. Применить явный список `excluded.txt`: 518 алфавитных токенов, включая
   неподтверждённые словарём записи, отдельные имена, обрывки и ошибочные написания.
4. Взять первые 5000 оставшихся записей в исходном порядке.

Словоформы не лемматизированы: `ir`, `voy`, `fui` — отдельные вопросы.
Заимствования, разговорные формы и грубая лексика сохранены с пояснениями.
Частотность субтитров не является универсальным рейтингом для любого контекста.

Уровень 1000 — первые 1000 записей результата, 3000 — первые 3000, 5000 — весь
результат. **Сначала уровень, затем тема, затем перемешивание.** Тот же набор
ограничивает неправильные варианты и индекс синонимов для ручного RU → ES.
Экспресс — до 20 случайных записей без повторов, полный — весь выбранный набор.

## Переводы

Для исходной сверки использованы испанский Викисловарь через экспорт
Vuizur / Kaikki / Wiktextract, русские значения и словоформы OpenRussian и
морфологический справочник Pattern / Fred F. Jehle. Версии, лицензии,
контрольные суммы и описание изменений: `data/spanish/references.json` и
[`NOTICE.md`](../data/spanish/NOTICE.md). Частотный список и языковые справочники
не подменяют друг друга.

Просмотрены все 5000 пар. Исправлены ложные совпадения значений и форм,
например `apellido` → «фамилия», `mayo` → «май», `uñas` → «ногти/когти»,
`madre` → «мать/мама», `hermanas` → «сёстры», `señoras` → «дамы/госпожи».
Учитываются распространённые значения: `tarjeta` принимает «карточка/карта»,
`prueba` — в том числе «доказательство», `carta` — «письмо/игральная карта/меню».
Пояснения и переводы в словаре русские, без оставленных английских черновиков.

Каждая запись содержит `topics`, а `topicTranslations` выбирает значения
в конкретной теме. Например:

- `banco`: работа → «банк», дом → «скамья/скамейка»;
- `vino`: еда → «вино», действия → «пришёл/пришла»;
- `copa`: еда → «бокал», досуг → «кубок», природа → «крона дерева»;
- `sobre`: пространственная тема принимает «на/над», но не «конверт».

Указанные дополнительные русские синонимы привязаны через `meaningAliases`
к точному значению, а не ко всем употреблениям испанского слова. Для всех тем
сохраняется только соответствующая часть `aliases`. В RU → ES принимаются
испанские слова с тем же основным русским значением внутри выбранного уровня
и темы, включая слова, не выпавшие в текущие 20 вопросов.

Регистр, пробелы, пунктуация и русское ё/е нормализуются. Испанские ударения и
`ñ` сохраняются: `si/sí`, `el/él`, `tu/tú`, `año/ano` — разные слова. Произвольные
опечатки не принимаются. Достаточно одного перечисленного перевода;
контекстные значения словаря не исчерпывают все возможные значения языка.
Автоматические проверки подтверждают структуру и согласованность тестов,
а не заменяют независимую экспертную языковую редактуру.

## Выражения и конструкции

В `expressions.tsv` — 500 формул общения, связок, устойчивых оборотов,
идиом и пословиц с русскими переводами. В `verb-constructions.tsv` — 500
перифраз, сочетаний с управлением и глагольных оборотов. Испанский язык не
имеет прямого структурного аналога английских phrasal verbs, поэтому второй
набор называется **«Глагольные конструкции»**.

Примеры: `pan comido` → «проще простого», `por si acaso` → «на всякий случай»,
`darse cuenta de` → «осознавать/замечать», `echar de menos` → «скучать по»,
`acabar de hacer algo` → «только что что-либо сделать».
Это авторская учебная подборка распространённых употреблений, не частотный
рейтинг. Для каждого набора доступны ES → RU и RU → ES, 500 или 20 вопросов,
только четыре варианта. Перевод выбранной ошибки, итоговый список экспресса,
бесконечные новые проходы и цветное кольцо работают как в английском разделе.

`phrase-exclusions.json` исключает из вариантов близкие или потенциально
неоднозначные сочетания. Совпадающие русские значения также исключаются
самим движком в обоих направлениях. Переводы, варианты и вопросы берутся
только из выбранного набора 500 записей.

## Проверки

`npm run check` проверяет воспроизводимость четырёх HTML и все модульные тесты.
Новые `tests/spanish.test.js`:

- сопоставляют все 5000 записей с исходным частотным срезом;
- проверяют все канонические переводы и перечисленные синонимы;
- перебирают все слова и варианты в каждом уровне, теме и направлении;
- проверяют 528 сочетаний уровня, темы, направления, формата и способа ответа;
- проверяют три попытки, пустой ответ, пропуск, блокировку повторного ответа,
  подсчёт результата и перемешивание;
- проходят обе подборки по 500 целиком в обоих направлениях;
- сохраняют независимые примеры перевода, отрицательные примеры и ударения.

Браузерные команды (Python + Playwright + Chromium):

```sh
python tests/browser-spanish.py
QUIZ_LANGUAGE=es python tests/browser-compat.py
QUIZ_LANGUAGE=es python tests/browser-phrases.py
python tests/browser-compat.py
python tests/browser-phrases.py
python tests/browser-layout.py
```

`browser-spanish.py` проверяет 1056 сочетаний настроек: 528 в обычном режиме и
528 с удалёнными современными API, отсутствующими в старых Safari. Использует
реальные обработчики форм и кнопок: три попытки, раскрытие ответа, ручной переход,
автоматический переход после верного ввода, пропуск, перевод ошибки, результаты,
повторный проход и переключение EN/ES. Экспрессы проходят до конца.

`browser-compat.py` дополнительно использует настоящие touch-нажатия и формы
для 48 сочетаний на каждом языке и проверяет предупреждение при выключенном JS.
При проверке исправлен общий обработчик пропуска: браузерный `click.detail > 1`
может возникнуть после нажатия другой кнопки. Первое нажатие «Пропустить» теперь
засчитывается и в этом случае, а последовательный двойной пропуск блокируется.
Оба случая воспроизводятся в `browser-spanish.py`; изменение применяется к EN и ES.
`browser-phrases.py` проходит 4160 вопросов каждого языка (полные и экспресс,
два направления и два набора в двух профилях API).
`browser-layout.py` сравнивает 17 общих элементов всех четырёх страниц на
ширинах 320, 360, 390, 540, 600, 768, 1024, 1280 и 1440 px.

Это проверки в Chromium; они не являются испытаниями на физическом iPhone
или движке WebKit. На iPhone тест следует открывать по веб-ссылке в Safari:
предпросмотр HTML в «Файлах» или мессенджере может блокировать JavaScript.

## Сборка и публикация

Испанские страницы используют те же шаблоны, движок и геометрию, что английские;
палитра вынесена в `src/spanish.css`. Значения `english` во внутреннем формате
подборки — совместимый ключ общего движка; на испанской странице он содержит
испанский текст. В интерфейсе направления и атрибуты `lang` соответствуют ES/RU.

`npm run build` создаёт `index.html`, `phrases.html`, `spanish.html` и
`spanish-phrases.html`. Словари встроены, сетевые запросы при прохождении
не выполняются. Для сборки нужны только Node.js и локальные данные;
временные инструменты подготовки словаря не являются зависимостями приложения.

`npm run publish:pages` публикует четыре HTML, лицензии и испанскую атрибуцию
из сохранённого коммита в `gh-pages`, сохраняя её историю. Рабочая ветка при этом
не переключается; `master` и `main` не затрагиваются.
