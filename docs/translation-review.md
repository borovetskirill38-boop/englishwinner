# Проверка русских переводов и ручного ввода

Просмотрены все 5000 записей `data/translations.tsv`, включая существительные,
глаголы, прилагательные, наречия, служебные слова и словоформы. Проверены
распространённые русские соответствия, варианты формулировок и пропущенные
значения. Состав английских слов, исходная частота и их порядок не изменены.

После проверки 1368 слов имеют 3083 дополнительных допустимых варианта
ручного ввода. В основные переводы добавлены 76 распространённых значений,
которых раньше не было; это значения тех же 5000 слов.

## Исправления

| Английское слово | Допустимые ответы и значения |
| --- | --- |
| card | карточка, карта; открытка в соответствующей теме |
| proof | доказательство, подтверждение, свидетельство |
| evidence | доказательство, доказательства, улика, улики |
| book | книга, книжка; бронировать, забронировать, резервировать |
| bank | банк; берег реки, берег |
| fine | прекрасный; в порядке; штраф; тонкий |
| check | проверять, проверить; проверка; чек |
| can | мочь; уметь; банка, консервная банка |
| date | дата; свидание; финик |
| may | мочь; иметь разрешение; май |

Слово `proof` уже содержало значение «доказательство»; для него добавлены
независимые регрессионные проверки и другие подходящие варианты. У `card`
отсутствовала «карта», у `evidence` — единственное число «доказательство».

## Привязка синонимов к значению

`data/answer-aliases.json` хранит объект по английскому слову. Его ключи —
точные значения из `data/translations.tsv`, значения — массивы русских синонимов.
Например:

```json
{
  "bank": {
    "берег реки": ["берег"]
  },
  "book": {
    "книга": ["книжка"],
    "бронировать": ["забронировать", "резервировать"]
  }
}
```

В общем режиме принимаются все значения слова и их синонимы. В тематическом
режиме `data/topic-translations.json` выбирает значения, а проверка сохраняет
только связанные с ними синонимы. Раньше тематическое ограничение удаляло все
синонимы у многозначного слова. Теперь «берег» принимается в природе, а «книжка»
не принимается вместо бронирования в работе.

Новые значения внесены в тематическую разметку явно. Например, «открытка»
у `card` не подмешивается в технику, а «штраф» у `fine` — в признаки и свойства.
Сначала по-прежнему отбирается частотный уровень, затем тема. Русские синонимы
не расширяют набор английских слов обратного теста.

## Проверки

- Все значения и дополнительные варианты всех 5000 слов принимаются при ручном
  вводе, включая выбранные темы и каждый частотный уровень.
- Независимые примеры проверяют `card`, `proof`, `evidence` и другие исправления,
  правильный счёт, переход к следующему слову и границы между значениями.
- Английские синонимы обратного режима ограничены выбранными уровнем и темой.
- Наборы из четырёх вариантов проверяются на единственный верный ответ,
  включая пересечение новых синонимов.
- Сохраняются три попытки, подсчёт ошибок, экспресс-режим и итоговый список слов.

Проверка не использует приблизительное совпадение по части слова, внешние API
или автоматическое угадывание по похожему написанию. Допустимые варианты
хранятся в данных, проходят проверки и доступны в автономном HTML.
