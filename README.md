# English Winner

Тест на 5000 частотных английских слов в двух направлениях:
**английский → русский** и **русский → английский**. Работает без интернета,
сервера, установки библиотек и регистрации.

В каждом направлении доступны **полный тест на 5000 слов** и
**экспресс-тест на 20 случайных слов**, а также два способа ответа:
**выбор из четырёх вариантов** и **ручной ввод перевода**.

## Как открыть

Скачайте **`index.html`** и откройте его двойным щелчком в современном браузере
(Chrome, Edge, Firefox или Safari). Для самого теста нужен только этот файл.
На Android откройте скачанный файл в браузере с поддержкой JavaScript.
На iPhone используйте **ссылку на веб-страницу в Safari**: «Файлы» и мессенджеры
могут показывать HTML в предпросмотре без выполнения JavaScript. Сам HTML
не может включить скрипты в таком просмотрщике. Если приложение не запустилось,
файл показывает объяснение и ссылку на веб-версию; кнопка старта включается
только после успешной инициализации.

### Веб-версия для iPhone

Для публикации подготовлена ветка **`gh-pages`** с готовым HTML и лицензиями.
Владелец репозитория один раз выбирает:
**Settings → Pages → Build and deployment → Deploy from a branch →
gh-pages → /(root) → Save**.

После завершения публикации открывайте в Safari:
https://borovetskirill38-boop.github.io/englishwinner/

До включения Pages адрес может отвечать 404. В текущей облачной среде доступ
к GitHub API ограничен сетевой политикой, поэтому включение Pages выполняется
в настройках репозитория. Скачивание страницы обратно в «Файлы» возвращает
проблему предпросмотра. После загрузки веб-страницы тесту не нужны сетевые запросы;
повторное открытие ссылки без сети не гарантируется.

Для обновления сайта после изменений выполните `npm run build`, сохраните
изменения коммитом, затем запустите `npm run publish:pages`.
Команда публикует только HTML и лицензии из текущего коммита обычным Git push,
сохраняет историю публикаций и не переключает рабочую ветку. GitHub Pages
обновляет сайт после публикации в `gh-pages`.

### Как проходить

1. Выберите направление **EN → RU** или **RU → EN**, формат **полный** или
   **экспресс** и способ ответа **4 варианта** или **Ручной ввод**. Нажмите «Начать тест».
2. Выберите один из четырёх переводов или введите перевод и нажмите
   «Проверить» (**Enter**). Неверный ответ подсвечивается красным.
3. В режиме вариантов нажмите «Следующее слово»; клавиши **1–4** выбирают ответ,
   **Enter** продолжает после ответа. При ручном вводе правильный ответ
   автоматически открывает следующий вопрос; ошибку можно исправить или пропустить.
4. После 5000 слов полного теста или 20 слов экспресс-теста появится итог.
   Кнопка «Пройти ещё раз» или «Ещё 20 слов» запускает новый проход.

В режиме **EN → RU** дано английское слово и четыре русских варианта перевода.
В режиме **RU → EN** дан русский перевод и четыре английских варианта.
При выборе из вариантов ровно один ответ правильный. В ручном режиме вместо
вариантов показывается поле ввода.

## Ручной ввод

Работает в обоих направлениях и с обоими размерами прохода — 5000 и 20 слов.

- Введите перевод и нажмите **Enter** или **«Проверить»**. Правильный ответ
  засчитывается один раз, и сразу появляется следующее слово с пустым полем ввода.
- Неверный ответ подсвечивает поле красным и оставляет тот же вопрос. Можно
  исправляться сколько угодно: сами попытки не меняют статистику.
- Если затем ввести верный перевод, слово засчитывается как правильное.
- **«Пропустить слово — ошибка»** сразу переходит дальше и засчитывает ровно
  одну ошибку, даже если до этого не было попыток.
- После перехода сверху показан результат предыдущего слова. При пропуске
  также показывается правильный перевод. После последнего слова открывается итог.

Принимается одно из значений словаря или дополнительный синоним из
`data/answer-aliases.json`, например `кот` для `cat` и `пёс` для `dog`. Пояснения
в скобках вводить не нужно. Регистр, лишние пробелы, знаки препинания и `ё/е`
нормализуются; опечатки внутри слов автоматически не исправляются.

В RU → EN подходят английские слова из словаря с тем же русским значением,
например `job` и `work` для «работа», даже если синоним не попал в экспресс-подборку.
Указанные в вопросе уточнения значения и времени сохраняются: «часы (единицы
времени)» — `hours`, а не `clock`. Для глагола можно добавить `to`, например
`to go` вместо `go`. Проверка целиком локальная, внешние переводчики не используются.

## Проходы и повторения

Полный проход включает все 5000 английских слов ровно по одному разу.
Экспресс-проход включает 20 случайных английских слов из всего словаря,
без повторов внутри подборки. При каждом новом экспресс-проходе 20 слов
выбираются заново; между проходами отдельные слова могут совпадать.
Порядок слов и расположение вариантов перемешиваются алгоритмом Фишера — Йетса.
Проходы можно повторять сколько угодно; «Новый проход» начинает новый тест
в текущем направлении и формате.
«Сменить режим» рядом с индикатором направления возвращает к выбору. После
итога также доступна кнопка «Выбрать другой режим». Новый проход и смена
направления или формата сбрасывают счёт, каждый проход начинается заново.
Повторное нажатие на ответ не изменяет результат. Таймера нет, обновление
страницы сбрасывает проход. Данные никуда не отправляются.

## Откуда слова

Источник частотности: **FrequencyWords, English 2018, OpenSubtitles**, автор
Hermit Dave и участники OpenSubtitles:

https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/en/en_50k.txt

Это частотность **разговорной речи в субтитрах**, а не универсальный рейтинг
для любой области английского. Выбраны первые 5000 слов после фильтрации
неалфавитных токенов, одиночных букв (кроме `a` и `i`) и явного стоп-листа
`data/excluded.txt`: имён людей, ряда географических названий, обрывков
сокращений, шумовых помет и непрозрачных сокращений. Словоформы не объединены:
например, `go`, `went` и `gone` — разные вопросы. Разговорные и грубые слова
сохранены, их переводы отмечены.

Русские переводы подготовлены для этого проекта, у многозначных слов указаны
несколько основных значений. В режиме EN → RU в вариантах показывается первое
значение. В режиме RU → EN это значение становится вопросом, а английское
слово — правильным ответом. После ответа в обоих режимах виден полный перевод.
У английских синонимов и некоторых словоформ могут совпадать русские вопросы;
это разные английские слова. Внутри любого прохода английские слова не повторяются.

Три неверных варианта берутся из отдельного двуязычного набора конкретных
значений `data/distractors.json`, чтобы синонимы вроде
`job` / `work` или `big` / `large` не давали два правильных ответа. Есть
проверки совпадений и исключения для пересекающихся значений. Тест проверяет
узнавание слов; он не заменяет изучение употребления слов в контексте.

Снимок частотных данных содержит первые 5788 строк исходного файла. Метаданные,
версия источника и SHA-256 сохранены в `data/source.json`. Изменения относительно
источника: фильтрация, выбор 5000 слов, добавление русских переводов и вариантов
ответов. Данные и переводы: **CC BY-SA 4.0**, полный текст в
`licenses/CC-BY-SA-4.0.txt`. Код приложения: **MIT**, см. `LICENSE`. Атрибуция
также встроена в HTML, в раздел «О словаре и правилах».

## Разработка и проверки

Node.js **18+**, внешние npm-зависимости не нужны.

```sh
npm run build  # собрать переносимый index.html из src/ и data/
npm test       # проверка данных, вариантов, перемешивания и полного прохода
npm run check  # дополнительно убедиться, что index.html актуален
```

`index.html` хранится в Git и готов к открытию. Меняйте `src/` и `data/`, затем
пересобирайте HTML. Контрольная сумма защищает исходный снимок частотности от
случайных изменений.

Проверка в настоящем Chromium, без доступа к интернету:

```sh
# Нужны Python с установленным playwright и Chromium.
python tests/browser.py
python tests/browser-typing.py
python tests/browser-compat.py
```

Тест передаёт браузеру точное содержимое `index.html` при выключенной сети:
управляемый Chromium облачной среды запрещает переходы на `file://` своей
политикой. Эта политика не меняется. Обычный браузер пользователя открывает
самодостаточный HTML напрямую; приложению не нужны загрузки соседних файлов.

Первый браузерный тест проверяет выбор и переключение направления и формата, цвета, клавиатуру,
блокировку повторного ответа, два полных прохода по 5000 слов и четыре
экспресс-прохода по 20 слов (по два в каждом направлении). Всего 10080 вопросов
в завершённых проходах. Проверяются новые случайные подборки, сброс результата,
переход между полным и экспресс-форматами, адаптивность на ширинах 320, 390,
768 и 1280 пикселей и отсутствие сетевых запросов.
Вторая проверка завершает четыре прохода с ручным вводом — по 5000 и 20 слов
в каждом направлении (10040 вопросов), проверяет исправления без штрафа,
автоматический переход, пропуски, пустой ввод, повторный запуск, возврат к
вариантам ответа и мобильную вёрстку. Все восемь сочетаний настроек проверяются офлайн.
Третья проверка открывает HTML через локальный HTTP-сервер, отключает сеть
после загрузки и использует касания на мобильном экране во всех восьми сочетаниях.
Она повторяет проверку с отключёнными `Object.hasOwn`, `String.replaceAll`,
`replaceChildren` и `replaceWith`, а также проверяет сообщение при отключённом
JavaScript. Это проверка совместимости в Chromium, не запуск Safari/WebKit
и не проверка на физическом iPhone. Скрипты приложения используют синтаксис
ES2017; зависимости от приватных методов классов, optional chaining и
перечисленных новых API удалены для совместимости со старыми Safari.
Путь к браузеру при необходимости: `CHROMIUM_PATH=/path/to/chromium`.
Скриншоты по умолчанию сохраняются вне репозитория в
`/tmp/englishwinner-screenshots`; путь можно изменить через `QUIZ_SCREENSHOTS`.
