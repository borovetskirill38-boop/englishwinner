# English Winner

Тест на 3000 частотных английских слов в двух направлениях:
**английский → русский** и **русский → английский**. Работает без интернета,
сервера, установки библиотек и регистрации.

В каждом направлении доступны **полный тест на 3000 слов** и
**экспресс-тест на 20 случайных слов**.

## Как открыть

Скачайте **`index.html`** и откройте его двойным щелчком в современном браузере
(Chrome, Edge, Firefox или Safari). Для самого теста нужен только этот файл.
На телефоне откройте скачанный файл именно в браузере с поддержкой JavaScript,
а не в просмотрщике документов.

1. Выберите направление **EN → RU** или **RU → EN** и формат: **полный** или
   **экспресс**, затем нажмите «Начать тест».
2. Выберите один из четырёх переводов. Правильный ответ станет зелёным;
   ошибочный — красным. Под вариантами появится результат и полный перевод.
3. Нажмите «Следующее слово». Для клавиатуры: **1–4** — ответ, **Enter** —
   следующий вопрос после ответа.
4. После 3000 слов полного теста или 20 слов экспресс-теста появится итог.
   Кнопка «Пройти ещё раз» или «Ещё 20 слов» запускает новый проход.

В режиме **EN → RU** дано английское слово и четыре русских варианта перевода.
В режиме **RU → EN** дан русский перевод и четыре английских варианта.
В обоих режимах ровно один вариант правильный.

Полный проход включает все 3000 английских слов ровно по одному разу.
Экспресс-проход включает 20 случайных английских слов из всего словаря,
без повторов внутри подборки. При каждом новом экспресс-проходе 20 слов
выбираются заново; между проходами отдельные слова могут совпадать.
Порядок слов и расположение вариантов перемешиваются алгоритмом Фишера — Йетса.
Проходы можно повторять сколько угодно; «Новый проход» начинает новый тест
в текущем направлении и формате.
«Сменить режим» рядом с индикатором направления возвращает к выбору. После
итога также доступна кнопка «Выбрать другой режим». Новый проход и смена
направления или формата сбрасывают счёт, каждый проход начинается заново.
Повторное нажатие на ответ не изменяет результат. Таймера нет, обновление
страницы сбрасывает проход. Данные никуда не отправляются.

## Откуда слова

Источник частотности: **FrequencyWords, English 2018, OpenSubtitles**, автор
Hermit Dave и участники OpenSubtitles:

https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/en/en_50k.txt

Это частотность **разговорной речи в субтитрах**, а не универсальный рейтинг
для любой области английского. Выбраны первые 3000 слов после фильтрации
неалфавитных токенов, одиночных букв (кроме `a` и `i`) и явного стоп-листа
`data/excluded.txt`: имён людей, ряда географических названий, обрывков
сокращений, шумовых помет и непрозрачных сокращений. Словоформы не объединены:
например, `go`, `went` и `gone` — разные вопросы. Разговорные и грубые слова
сохранены, их переводы отмечены.

Русские переводы подготовлены для этого проекта, у многозначных слов указаны
несколько основных значений. В режиме EN → RU в вариантах показывается первое
значение. В режиме RU → EN это значение становится вопросом, а английское
слово — правильным ответом. После ответа в обоих режимах виден полный перевод.
У английских синонимов и некоторых словоформ могут совпадать русские вопросы;
это разные английские слова. Внутри любого прохода английские слова не повторяются.

Три неверных варианта берутся из отдельного двуязычного набора конкретных
значений `data/distractors.json`, чтобы синонимы вроде
`job` / `work` или `big` / `large` не давали два правильных ответа. Есть
проверки совпадений и исключения для пересекающихся значений. Тест проверяет
узнавание слов; он не заменяет изучение употребления слов в контексте.

Снимок частотных данных содержит первые 3379 строк исходного файла. Метаданные,
версия источника и SHA-256 сохранены в `data/source.json`. Изменения относительно
источника: фильтрация, выбор 3000 слов, добавление русских переводов и вариантов
ответов. Данные и переводы: **CC BY-SA 4.0**, полный текст в
`licenses/CC-BY-SA-4.0.txt`. Код приложения: **MIT**, см. `LICENSE`. Атрибуция
также встроена в HTML, в раздел «О словаре и правилах».

## Разработка и проверки

Node.js **18+**, внешние npm-зависимости не нужны.

```sh
npm run build  # собрать переносимый index.html из src/ и data/
npm test       # проверка данных, вариантов, перемешивания и полного прохода
npm run check  # дополнительно убедиться, что index.html актуален
```

`index.html` хранится в Git и готов к открытию. Меняйте `src/` и `data/`, затем
пересобирайте HTML. Контрольная сумма защищает исходный снимок частотности от
случайных изменений.

Проверка в настоящем Chromium, без доступа к интернету:

```sh
# Нужны Python с установленным playwright и Chromium.
python tests/browser.py
```

Тест передаёт браузеру точное содержимое `index.html` при выключенной сети:
управляемый Chromium облачной среды запрещает переходы на `file://` своей
политикой. Эта политика не меняется. Обычный браузер пользователя открывает
самодостаточный HTML напрямую; приложению не нужны загрузки соседних файлов.

Тест проверяет выбор и переключение направления и формата, цвета, клавиатуру,
блокировку повторного ответа, два полных прохода по 3000 слов и четыре
экспресс-прохода по 20 слов (по два в каждом направлении). Всего 6080 вопросов
в завершённых проходах. Проверяются новые случайные подборки, сброс результата,
переход между полным и экспресс-форматами, адаптивность на ширинах 320, 390,
768 и 1280 пикселей и отсутствие сетевых запросов.
Путь к браузеру при необходимости: `CHROMIUM_PATH=/path/to/chromium`.
Скриншоты по умолчанию сохраняются вне репозитория в
`/tmp/englishwinner-screenshots`; путь можно изменить через `QUIZ_SCREENSHOTS`.
